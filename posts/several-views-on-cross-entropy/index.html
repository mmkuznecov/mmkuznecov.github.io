Several views on cross-entropy

2026-05-31

Cross-entropy is the loss you reach for almost by reflex in classification. But the same object shows up under several different names depending on which field you ask. They are all the same equation; only the story changes. Everything below hangs off one identity:

$$ H(p, q_\theta) \;=\; H(p) \;+\; D_{\mathrm{KL}}(p \,\|\, q_\theta) $$

Since $H(p)$ does not depend on the model parameters $\theta$, minimizing cross-entropy is exactly minimizing the KL divergence from the data distribution to the model. The views below are different ways of reading this fact.

1.Maximum likelihood

Cross-entropy is the expected negative log-likelihood:

$$ H(p, q_\theta) = -\,\mathbb{E}_{x \sim p}\big[\log q_\theta(x)\big]. $$

With samples $x_1, \dots, x_n \sim p$ this is approximated by the empirical mean,

$$ H(p, q_\theta) \approx -\frac{1}{n} \sum_{i=1}^{n} \log q_\theta(x_i), $$

which is precisely the negative log-likelihood. So minimizing cross-entropy is maximizing likelihood:

$$ \arg\min_\theta H(p, q_\theta) = \arg\max_\theta \sum_{i=1}^{n} \log q_\theta(x_i). $$

2.KL divergence

Starting from the definition of KL divergence and splitting the logarithm,

$$ D_{\mathrm{KL}}(p \,\|\, q_\theta) = \mathbb{E}_p\!\left[\log \frac{p(x)}{q_\theta(x)}\right] = \mathbb{E}_p[\log p(x)] - \mathbb{E}_p[\log q_\theta(x)]. $$

Recognizing $H(p) = -\,\mathbb{E}_p[\log p(x)]$ and $H(p,q_\theta) = -\,\mathbb{E}_p[\log q_\theta(x)]$ gives $D_{\mathrm{KL}}(p \,\|\, q_\theta) = H(p,q_\theta) - H(p)$, which rearranges into the identity at the top. This is the information-theoretic reading: training pulls the model distribution toward the true one.

3.Coding theory

Entropy $H(p)$ is the optimal expected code length when you know the true distribution $p$. Cross-entropy $H(p,q)$ is the expected code length when the data really comes from $p$ but you encode it with a code optimized for $q$. The gap between them is the price of using the wrong code:

$$ D_{\mathrm{KL}}(p \,\|\, q) = H(p, q) - H(p). $$

In one line:

cross-entropy = irreducible uncertainty + model-mismatch penalty.

4.Classification

For single-label classification the target $p$ is one-hot on the true class $y$, so the sum collapses to a single term:

$$ H(p, q) = -\sum_k p(k)\,\log q(k) = -\log q(y). $$

The loss depends only on the probability the model assigns to the correct class. A confident-correct prediction $q(y)=0.9$ costs $-\log 0.9 \approx 0.11$, while a confident-wrong one $q(y)=0.01$ costs $-\log 0.01 \approx 4.61$. The logarithm is what makes the penalty for confident mistakes blow up.

5.Proper scoring rule

Cross-entropy is a proper scoring rule: its expected value is minimized when the model reports the true probabilities. If the true conditional is $p(y \mid x)$, the optimum is

$$ q_\theta(y \mid x) = p(y \mid x). $$

So it rewards more than getting the label right — it rewards calibrated probabilities over the whole distribution. That is why it is trained against instead of accuracy, which only looks at the $\arg\max$.

6.Forward vs. reverse KL

Minimizing cross-entropy minimizes the forward KL, $D_{\mathrm{KL}}(p \,\|\, q_\theta)$. It pays a large cost wherever $p$ has mass but $q_\theta$ does not, so it is mode-covering: the model is pushed to spread over every mode of $p$. The reverse direction, $D_{\mathrm{KL}}(q_\theta \,\|\, p)$, tends to be mode-seeking — it can lock onto a single mode and ignore the rest. The distinction is central to variational inference and generative modeling.
